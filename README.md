# KineType Studio 

**一个动态字幕生成器，它复刻的是 TypeMonkey /「倒鸭子」这类快闪文字混排效果，不需要 After Effects，就可以完成这种效果。**

---

## 本地部署

### 环境要求

- Node.js **20.19+** 或 **22.12+**
- Chrome / Edge（导出依赖 `MediaRecorder` 或 WebCodecs）

### 启动开发版

```bash
git clone https://github.com/xzhnew/kinetype.git
cd kinetype/web-ui
npm install
npm run dev
```

打开 <http://localhost:63200>。

### 构建与本地预览

```bash
npm run build      # 产物在 web-ui/dist/
npm run preview    # 预览构建结果，http://localhost:63201
```

`dist/` 是纯静态文件，扔到任何静态服务器都能跑（`base` 已设为相对路径）。

> 仓库里另有一套可选的 Python 离线批量渲染（`web-ui/kinetype/`），
> 需要 Pillow + ffmpeg，适合服务器批量出片；网页版是主路径，这里不展开。

## 脚本语法

### 1. 一行一拍

- **一个非空行 = 一个节拍**，按行切分，不按字符数。
- 行内的 `。！？!?；;…` 会额外切一拍；`，,、：:—～` 在字数够长时也会切。
- 空行和以 `#` 开头的行会被跳过（可用来写注释、分段）。
- `|` 强制换行（同一个节拍里断行，不移到下一拍）。

```text
你好，这里是 KineType。
# 这一行是注释，不会出现在视频里
第一行|第二行
```

### 2. 样式块 `{ ... }`

`{属性:值 属性:值}` 打开一个样式块，**块在行尾自动结束**，也可以显式关闭：

| 写法 | 作用 |
|---|---|
| `{/}` | 关闭当前整个样式块 |
| `{/color}` | 只撤销 `color` 这一个属性，其余保留 |

样式可以嵌套，内层覆盖外层，和 HTML 的 `<b><i>` 一个道理。

| 指令 | 取值 | 说明 |
|---|---|---|
| `size` | 数字，如 `1.4` | 字号倍数，`1` 为原始大小 |
| `font` | 字体别名，如 `kai` | 对应设置里的「字体对照表」，没有别名时写字体名 |
| `color` | `#FFD84D` / `red` | 文字颜色 |
| `weight` | `700` / `bold` / `normal` | 字重，`bold` = 900 |
| `bold` | 无值 | 等价于加粗 |
| `shadow` | `off` / 数字 | 阴影强度，`off` 关闭 |
| `stroke` | `#00E5FF` / `off` | 描边颜色，`off` 关闭 |
| `strokew` | 数字，如 `0.12` | 描边宽度（em） |
| `spacing` | 数字，如 `0.1` | 字距（em） |
| `hl` | 无值 | 高亮底色 |

```text
{size:1.6 color:#FFD84D}这一拍又大又黄{/}
{color:#4CC2FF}蓝色{/color}，然后恢复外层颜色
```

### 3. 两个快捷写法

| 语法 | 等价于 |
|---|---|
| `[这几个字]` | 高亮 |
| `**这几个字**` | 加粗 |

### 4. 整块旋转

`{转}` 让**它之前的行**作为一整块旋转 90°，标记这一行及之后的行保持正的。

| 写法 | 说明 |
|---|---|
| `{转}` | 默认角度（受「旋转方向」下拉框影响） |
| `{转:90}` / `{转:-90}` | 指定角度 |
| `{rot:90}` | 同上，英文写法 |

```text
第一行
第二行
{转:-90}
第三行
```

### 5. 转义

反斜杠可以转义语法字符，让它们按普通文字显示：

```text
\{不是样式\}  \[不是高亮\]  \*不是加粗\*  \|不是换行
```

### 6. 完整示例

```text
{size:1.2 color:#16213E}演示开始{/}
{font:kai size:1.4}这句话用楷体，字号 1.4 倍{/}
{color:#E94560}[重点]{/color} 前后都可以加样式
**加粗**和[高亮]可以混在{}外面
第一行|第二行
{转:-90}
转过来了
```

## 导出

在标题栏填写导出名称，选择画幅、清晰度和格式，点「导出」即可。
浏览器支持时优先 WebCodecs 硬件编码，其次软件编码，最后回退 `MediaRecorder`。
导出按钮的悬停提示会显示当前使用的编码档位。
